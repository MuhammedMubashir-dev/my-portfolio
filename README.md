# Muhammed Mubashir Portfolio

Personal portfolio website for Muhammed Mubashir, a Junior Full Stack Developer focused on
Flutter mobile and POS applications, with React Native experience on Android/iOS and supporting
React/Next.js commerce work.

## Live Website

https://muhammed-mubashir-portfolio.netlify.app/

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- Netlify

## Features

- Responsive portfolio layout
- Project case-study cards
- Skills and production impact sections
- Accessible navigation and contact links
- Flutter résumé downloads in PDF and Word formats
